#  PoliMatch - ESPOL

## Descripción del proyecto

PoliMatch es una propuesta de sitio web para que la comunidad politécnica encuentre información sobre los partidos de fútbol que se organizan en ESPOL. Nuestro objetivo es reunir información sobre horarios, pruebas de selección y actividades deportivas de las asociaciones.

La idea surge a partir de las entrevistas realizadas, donde identificamos necesidades relacionadas con la organización de los partidos, la difusión de horarios y la participación de los estudiantes.

Con este proyecto queremos reunir esta información en un solo lugar para que sea más fácil conocer los próximos encuentros y las actividades organizadas por las asociaciones.

## Objetivo

Desarrollar una página web que permita a los estudiantes de ESPOL consultar información sobre partidos de fútbol, pruebas de selección y actividades deportivas, facilitando su participación.

## Secciones de la página

| Sección | Contenido previsto |
| --- | --- |
| **Inicio** | Presentación de la página, anuncios y próximos encuentros. |
| **Calendario de partidos** | Fechas, horarios, canchas y asociaciones organizadoras. |
| **Partidos disponibles** | Información sobre encuentros y posibles cupos para participar. |
| **Pruebas de selección** | Fechas, horarios, condiciones de participación y, si se implementa, inscripción y turnos. |
| **Canchas y reservas** | Información de los espacios deportivos y orientación para solicitar el uso de canchas mediante Bienestar Politécnico. |
| **Asociaciones deportivas** | Información sobre las asociaciones y sus actividades. |
| **Información de participación** | Reglas generales, requisitos y posibles contribuciones para el arbitraje. |

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

La tipografía usa Google Fonts cuando hay conexión; si no, se muestran fuentes de respaldo.

El diseño está inspirado en la plantilla [TXT de HTML5 UP](https://html5up.net/txt). Se conserva el crédito de inspiración a HTML5 UP y su [licencia CC BY 3.0](https://html5up.net/license).

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre `index.html` en un navegador web moderno.
3. Alternativamente, ejecuta un servidor local:

   ```bash
   python -m http.server 8000
   ```

   Luego abre `http://localhost:8000`.
